Online multiplayer — not connected in this build

Online play needs a live backend, which a static page cannot provide by itself. The planned architecture for SAINDHAV ARENA on Cloudflare is: Cloudflare Workers + Durable Objects over WebSockets — one Durable Object per room holding synced state, with private room codes, waiting / ready, turn sync, reconnect and rematch handled in the Worker. That must be deployed and verified with two separate sessions before any “Online” button is shown as playable, so this page does not fake online opponents or rooms. Until that Worker is deployed in the GitHub repo (MAD234315/saindhav-arena) and connected to Cloudflare, use Single Player or Local 2 Players — both work offline after the page has loaded. If you open this page offline, online would be unavailable anyway, so the game will stay in its offline modes.
